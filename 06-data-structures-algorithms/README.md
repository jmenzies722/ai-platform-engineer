# 06 — Data Structures and Algorithms

Choose data structures and algorithms from required operations, invariants, and evidence rather than from memorized interview patterns. The sequence develops growth analysis, core structures and traversals, design paradigms, dynamic programming, and practical correctness arguments.

## What you will learn

By the end, you can define input size, compare time and space growth, select structures by workload, state loop and representation invariants, implement search and traversal safely, recognize divide-and-conquer, greedy, and dynamic-programming shapes, and validate an optimized algorithm against a simple reference.

## Practice

Complete each lesson’s bounded exercise, then work through [Design, Prove, and Measure a Scheduler](./lab-design-prove-measure-scheduler.md). The lab begins with a deliberately simple reference before adding a heap and property-oriented checks.

Practice is part of the path, not an optional recap. Predict first, work only in disposable or explicitly scoped resources, compare expected and actual observations, and perform the documented cleanup.

## Ready to continue

Continue when you can write an operation table before choosing a structure, state the invariant behind binary search and graph traversal, solve and terminate a recurrence, explain when a greedy exchange argument is required, derive a dynamic-programming state and transition, and compare an optimized implementation with an obviously correct oracle across edge cases.
