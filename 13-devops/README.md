# 13 — DevOps

DevOps is an operating model for shortening safe feedback loops across development and operations, not a job title or a CI product.

## What you will learn

- Turn a change into a repeatable build, test, release, and recovery path.
- Prefer small batches, production feedback, and shared ownership.
- Design delivery controls around risk instead of ceremony.

## Lessons

1. [Feedback loops and shared ownership](01-feedback-and-ownership.md)
2. [Continuous integration and delivery](02-continuous-delivery.md)
3. [Safe changes and recovery](03-safe-change.md)

## Practice

Map one repository from commit to production. Mark every manual handoff, hidden credential, unrepeatable step, and recovery decision; then remove the smallest high-risk gap.

## Ready to continue

You can distinguish deployment from release, explain why smaller batches reduce risk, and design a pipeline that preserves evidence and supports rollback or roll-forward.
