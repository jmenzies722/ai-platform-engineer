# 13 — DevOps

DevOps is an operating model for shortening safe feedback loops across development and operations, not a job title or a CI product.

## What you will learn

- Turn a change into a repeatable build, test, release, and recovery path.
- Prefer small batches, production feedback, and shared ownership.
- Preserve immutable artifacts, provenance, and promotion evidence.
- Design change and software supply-chain controls around risk instead of ceremony.

You can distinguish integration, delivery, deployment, and release; trace a production artifact to reviewed source and build identity; constrain pipeline authority; and use production evidence to govern and improve changes.
