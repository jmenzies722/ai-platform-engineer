# Project Workspace

The portfolio targets and graduation criteria live in [PROJECTS.md](../PROJECTS.md). Each implementation should become an independent repository rather than being developed inside this curriculum.

This directory may hold curriculum-level project briefs, review rubrics, and links to external project repositories. It must not become a dump of tutorial copies or generated application scaffolds.

Start a brief with [templates/PROJECT.md](../templates/PROJECT.md). Before implementation, define the user, measurable outcome, constraints, non-goals, quality attributes, failure model, and smallest vertical slice that can produce evidence.
