# 02 — Python

Learn Python as a precise execution model, not a bag of syntax. The sequence moves from names and control flow through modules, collections, object protocols, iteration, resources, and dependable program boundaries. Read in order and type the examples; fluency comes from predicting behavior before running it.

## What you will learn

By the end, you can design small Python programs with explicit ownership and errors, choose collection operations intentionally, define useful types and protocols, stream data without accidental materialization, manage resources, package behavior into modules, and verify contracts with tests. The module teaches the standard language model; framework expertise comes later.

## Practice

Use each lesson’s bounded exercise, then complete [Build a Tested Streaming Package](./lab-tested-streaming-package.md). The lab combines modules, parsing, iteration, resource management, and tests without external dependencies.

Practice is part of the path, not an optional recap. Predict first, work only in disposable or explicitly scoped resources, compare expected and actual observations, and perform the documented cleanup.

## Ready to continue

Continue when you can predict aliasing and scope, write a narrow function contract, explain import behavior, select a collection from required operations, implement a small protocol, consume an iterator once without surprise, use a context manager for cleanup, and run the lab from a fresh interpreter with all tests passing.
