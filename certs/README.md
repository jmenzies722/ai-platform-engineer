# Certification overlays

Certification overlays are indexes into the existing curriculum. They do not
replace module order, repeat lesson material, or claim that an exam pass proves
production competence.

## Overlay contract

Every overlay must:

- use the certification owner's current, primary sources for exam names,
  domains, weights, task statements, and exam details;
- map every official task statement to existing lessons and to inspectable
  practice in labs, incident drills, projects, and competency gates;
- preserve the curriculum's Explain, Build, Debug, Operate, and Design evidence
  model in [PROGRESS.md](../PROGRESS.md);
- identify uncovered or thin product-specific practice instead of implying
  coverage;
- add an ordering and assessment lens, not a parallel certification course;
- link only to paths that exist in this repository and avoid copying lesson
  content.

Exam readiness and operating readiness are separate claims. A certification can
demonstrate knowledge of an exam blueprint. Operating competence requires
independent builds, diagnosed failures, safe operation, design judgment, and
repeatable evidence.
