# 20 — Security

Security is the work of making trust explicit, limiting what compromise can do, and preserving evidence for response.

## What you will learn

- Model assets, actors, trust boundaries, and plausible abuse.
- Apply strong identity, least privilege, and safe secret handling.
- Build security checks into delivery and prepare for incidents.

## Lessons

1. [Threat modeling and trust boundaries](01-threat-modeling.md)
2. [Identity, authorization, and secrets](02-identity-and-secrets.md)
3. [Secure delivery and response](03-secure-delivery-and-response.md)

## Practice

Threat-model a small web service. Include its CI system, artifact registry, cloud identity, datastore, administrators, and one compromised dependency.

## Ready to continue

You can name protected assets and abuse cases, distinguish authentication from authorization, scope machine identity, and preserve useful evidence during containment.
