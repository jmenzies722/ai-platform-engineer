# Cheatsheets

Cheatsheets are compact retrieval aids written **after** understanding a domain. They should accelerate safe execution without hiding mechanisms.

Each cheatsheet should include:

- task or symptom it addresses;
- commands with side effects and privilege requirements marked;
- expected output shape and interpretation;
- common ambiguity and failure signatures;
- links to the lesson, lab, and canonical documentation;
- tool and platform version where semantics vary.

A cheatsheet is not a substitute for a runbook, lesson, or reference manual. Never include credentials, organization-specific sensitive data, or destructive commands without explicit safeguards.
