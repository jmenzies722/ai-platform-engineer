# 01 — Software Foundations

See how source becomes a running process, how programs use memory and files, and how concurrency changes execution. Read the lessons in order: each one assumes the model and vocabulary established immediately before it.

## What you will learn

By the end, you can explain the central mechanism in plain language, inspect it with a small command or program, recognize common failure modes, and choose evidence before changing a system.
