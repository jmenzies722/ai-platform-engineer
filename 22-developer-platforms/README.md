# 22 — Developer Platforms

An internal developer platform exposes platform capabilities through a coherent product surface: a trustworthy catalog, reusable templates, durable workflows, APIs, documentation, policy feedback, and operational evidence.

## What you will learn

- Build a catalog around authoritative ownership, relationships, and lifecycle.
- Design secure templates, rerunnable workflows, portals, APIs, and plugins.
- Operate golden paths and scorecards as governed products with measurable outcomes.

## Practice

Complete the lessons in order, then perform the IDP design review in lesson 8. The capstone requires a catalog model, template and workflow boundary, interface and plugin architecture, scorecard, threat model, golden-path lifecycle, and evidence plan.

## Ready to continue

You can trace authoritative metadata into a catalog, design resumable self-service, keep portal and API behavior coherent, constrain plugins, make scorecards actionable, secure delegated execution, and retire a golden path without stranding teams.
